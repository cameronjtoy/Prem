# Welcome to Prem

This vault is a small example of how a lab keeps its records in one place. Everything here is a plain markdown file, so it also opens in any other editor and can be kept in git.

## What's in here
- **Protocols**: step-by-step methods the lab follows, such as [[Plasmid miniprep]]. A protocol has a **Start run** button.
- **Notebook**: one person's entries, filed by year. Press **⌘T** for today's entry. Experiments like [[Ligation of insert into pUC19]] record aims, methods, results and attachments.
- **Notebook/Runs**: each time a protocol is run, Prem creates a run with the steps copied in and records when each one was ticked, for example [[Plasmid miniprep run 2026-09-29 1410]].
- **Workflows and Jobs**: a workflow such as [[Plasmid prep]] lists a process's stages, each with a protocol and who does it. **New job** starts one pass through it; the job's bar starts each stage's run and hands the job on, as in [[Plasmid prep job 2026-09-28 0900]].
- **Samples**: one note per sample, such as [[S-0001]]. Experiments and runs link to the samples they used, so a sample's **Backlinks** show everywhere it appears.

## Try it
- Open [[Plasmid miniprep]] and press **Start run**. Tick a step and watch the time appear next to it.
- Open [[Plasmid prep]] and press **New job**, then **Start run** for its first stage.
- Open [[Ligation of insert into pUC19]] and drop an image or a CSV onto it.
- Press **⌘K** and search for `ligase`.
- Click the **History** button on any note to see every saved version.
- On an experiment, press **Sign…** to lock it. On a team vault, a colleague can then **Witness** it.

> Signed records can only be changed through an **amendment** with a reason. The signed version is kept in History.
