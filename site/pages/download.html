The first time you open Prem

The installers aren't signed yet, so macOS and Windows warn the first time you open Prem. You only need to get past this once.

  • macOS: open Prem, choose Done, then go to System Settings → Privacy & Security and choose Open Anyway.
  • Windows: on "Windows protected your PC", choose More info, then Run anyway.
  • Linux: make the AppImage executable, or install the .deb with sudo apt install ./Prem-….deb.

The install guide has the details, and how to check a download's checksum.

The lab server

To share one notebook across a lab, run the Prem server on a machine everyone can reach. It's a single program with no database: the notebook stays a folder you can back up. 

docker run -d -p 4747:4747 -v /srv/prem:/data ghcr.io/cameronjtoy/prem-server

The install guide covers the configuration file and creating a token for each person.
