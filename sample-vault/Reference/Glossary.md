# Glossary

| Term | Meaning |
| --- | --- |
| **ARPA** | Average revenue per account, per month |
| **CAC** | Customer acquisition cost |
| **COGS** | Cost of goods sold |
| **LTV** | Lifetime value of a customer — see [[Unit economics]] |
| **MTTR** | Mean time to recovery after an incident — see [[Incident response]] |
| **Canary** | A release sent to a small share of traffic first — see [[Deploy to production]] |
