# Welcome

This vault is a small example of how a team can keep its knowledge in one place.

## What's in here
- **Runbooks** — step-by-step guides such as [[Deploy to production]] and [[Incident response]]
- **Finance** — formulas the business runs on, like [[Unit economics]]
- **Reference** — shared definitions in the [[Glossary]]

## How to use it
- Type `[[` to link to another note. Links to notes that don't exist yet, like [[Onboarding checklist]], show up faded; click one to create it.
- The panel on the right shows every note that links to the one you're reading.
- Use **New from template** to start a runbook, meeting note or reference page with the right structure.
- Press ⌘G to see how everything connects.

> Notes are plain markdown files in this folder, so they can also be edited in any other editor or kept in git.
